Plant layout

Three feedstocks — scrap, core stock and sand. Sand becomes empty mould boxes at MB, which buffer JIT into core setting (CS); the core maker (CM) drops a core into each box (the box gains a black X). The mould-with-core is then issued to whichever pouring line (A1, A2, KW) is ready. The furnaces (F1, F2) sit ABOVE the lines and pour metal laterally into the boxes — they do not touch mould prep at all. Once poured the box fills with yellow metal and gains mass.

Castings flow into the pooled shakeout (SK) → pooled fettling (FT). The line then snakes back along the bottom row. Before each finishing step (SB, HT, MC, PT) a tiny diamond ⋄ decision node decides whether to send the casting forward or to bypass directly to QC (for as-cast, unfinished or unmachined orders).

Unit codes & QC rules
  • Tokens append per stage, joined by -: B(box) S(sand-press) C(core-set) P(pour) Cl(cool) Sh(shakeout) Ft(fettle) T(shot-blast) H(heat) M(machine) F(paint)
  • Colour letter follows B-: Y yellow, B blue, G green, X gray
  • QC accepts only the exact lineage:
    yellow → B-Y-S-C-P-Cl-Sh-Ft-T-H-M-F
    blue  → B-B-S-C-P-Cl-Sh-Ft-T-H
    green → B-G-S-P-Cl-Sh-Ft-T-H-M-F
    gray  → B-X-S-C-P-Cl-Sh-Ft
  • Anything else is rejected and counted in the header.

About this model

Places (circles) are bins where tokens accumulate. Transitions (rectangles) are machines that pull from input bins and push to output bins.

Click any machine to configure its tick interval and boost. Use the RHS panel for master control.

Routing is deterministic per colour (matching the factory schematic). Gray/blue skip some finishing steps.

Backpressure (master switch) slows firing when output bins are over-filled. Boost overrides backpressure.
